## 📱 **SMS SYSTEM:**

### **Current Mode**: Console (FREE)
- Messages print to server console
- Perfect for testing

### **For Production**:
1. Sign up for SMS provider (BulkSMS BD recommended)
2. Update `backend/settings.py`:
```python

SMS_SENDER_ID = 'YourSchool'
```
3. Start sending real SMS!

## 🚀 **DEPLOYMENT (Optional):**

### **For Production Deployment**:

1. **Update Settings**:
```python
DEBUG = False
ALLOWED_HOSTS = ['yourdomain.com']
```

2. **Set Up Database**:
- Use PostgreSQL instead of SQLite
- Update DATABASES in settings.py

3. **Configure Static Files**:
```bash
python manage.py collectstatic
```

4. **Set Up Domain**:
- Buy domain
- Configure DNS
- Set up SSL certificate

5. **Deploy**:
- Use DigitalOcean, AWS, or Heroku
- Follow their deployment guides
